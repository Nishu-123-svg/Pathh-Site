# नित्य नियम पूजा (Nitya Niyam Daily Prayers)

A clean, serene, and devotional serverless web application built with **Next.js (App Router)**, **Tailwind CSS**, and **Web Audio API** designed for daily prayer, chanting, and spiritual sadhana.

---

## 🌸 The 6 Sacred Daily Prayers Included

1. **श्री गणेश चालीसा (Shree Ganesh Chalisa)** - Complete with initial Doha, 38 Chaupais, and concluding Dohas.
2. **संकटनाशनं श्रीगणेशस्तोत्रम् (Sankata Nashanam Ganesha Stotram)** - 12 Holy Names of Lord Ganesha with full Phalashruti from Narada Purana.
3. **श्री गणेश जी की आरती (Shree Ganesh Ji Ki Aarti)** - Traditional "Jai Ganesh Jai Ganesh Deva" with chorus.
4. **श्री हनुमान चालीसा (Shree Hanuman Chalisa)** - Complete 40 Chaupais and opening/closing Dohas with high clarity typography.
5. **श्रीमद्भगवद्गीता - सप्तम अध्याय माहात्म्य (Shrimad Bhagavad Gita - Chapter 7 Mahatmya)** - Sacred dialogue between Lord Shiva and Mata Parvati.
6. **शिव यजुर मन्त्र एवं नित्य प्रार्थना स्तुति (Shiv Yajur Mantra & Nitya Stuti)** - Karpura Gauram, Ghalin Lotangan, Twameva Mata, Achyutam Keshavam, and Maha Mantra.

---

## ✨ Features

- **Continuous Prayer Flow**: All 6 prayers organized seamlessly with smooth scroll-spy navigation.
- **📿 Digital Jap Mala Counter**:
  - Interactive chanting beads with 11, 21, 54, and 108 milestone presets.
  - Round tracking, spacebar shortcut, tap vibration/sound, and Shankh/Gong celebration.
- **🔔 Authentic Temple Bell & 432 Hz Meditative Drone**:
  - Synthesized Web Audio Brass Temple Bell (Ghanti).
  - 432 Hz Om harmonic Tanpura background drone (100% offline, zero audio file dependencies).
- **🪔 Ceremonial Altar**: Interactive Diya (lighting/extinguishing) and Flower Offering (पुष्प अर्पण).
- **📜 Smart Reading Tools**:
  - **Hands-free Auto-Scroll** with configurable speeds (0.5x, 1x, 2x).
  - **Font Size Adjuster (A- / A+)** for effortless legibility.
  - **Romanized Transliteration** and **Hindi Bhavarth (Meaning)** toggle.
  - **Text-to-Speech (TTS)** voice reciting support.
  - **Distraction-free Zen Mode**.
- **📅 Daily Sadhana Streak Tracker**: Check off prayers completed today and maintain your daily streak stored locally.
- **🎨 3 Sacred Themes**:
  - *स्वर्ण सांध्य (Vedic Saffron & Gold)*
  - *चंदन प्रातः (Sandalwood Daylight)*
  - *निशा ध्यान (Temple Night Dark Mode)*
- **🖨️ Print & PDF Ready**: High contrast clean styling for physical printing or offline PDF generation.

## 🚀 Getting Started

### Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build Production

```bash
npm run build
npm start
```

---

## ☁️ Deploy to Vercel (1-Click Serverless)

This project is 100% serverless and native to Vercel:

1. Push your repository to GitHub / GitLab / Bitbucket.
2. Go to [vercel.com/new](https://vercel.com/new) and import your repository.
3. Click **Deploy**. Vercel will automatically detect Next.js and deploy it globally with edge CDN caching.
